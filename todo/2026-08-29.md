# 2026-08-29 — A roadmap, and most of its first phase

Two multi-agent workflows ran overnight: a judge panel on the tagline (41 candidates,
three independent lenses) and a five-dimension audit of the codebase, sequenced into a
roadmap and then attacked by two adversarial critics. Both critics disagreed with the
proposed ordering, and both were right. What follows is the corrected plan, and the
part of it that is already done.

## The tagline: keep it

41 candidates, scored by three judges on house voice, truthfulness, and
differentiation, ranked by *weakest* lens rather than total — a line one judge hates
is a bad tagline however much the others liked it. Several candidates were better
*sentences* than "Learn graphics by moving the numbers." None was a better *tagline*,
because the H1 sits between an eyebrow that already says "Interactive graphics labs"
and a subhead that already delivers the thesis; its job is to be the plain, complete
claim in the middle, and the challengers were all competing for a job the surrounding
copy had taken.

What the panel was right about was one level down:

- The home subhead is now one sentence instead of two. The old middle clause — "you
  cannot see a motion on a static page" — was doing work the H1 already does.
- The labs index took the best line on the shortlist: **"Printed matrices hold still.
  These do not."** It failed as an H1 because "These" had no antecedent on a social
  card; on the labs index the live matrices are directly below it.
- The tagline is now a single constant. It had been pasted into five places.

## What shipped

**Textures & Sampling** — the sixth lab. A ground plane running to the horizon: the
same texture magnified in the foreground and crushed into a few pixels at the back, so
one scene shows every sampler decision at once. All five minification filters, both
magnification filters, three wrap modes per axis. The texture is generated rather than
shipped, built to make sampling visible — one-pixel lines too fine to survive
minification, a cyan border so wrap seams read, an asymmetric amber marker so a
mirrored repeat cannot be mistaken for a plain one.

**The labs became a sequence.** Numbered, with declared prerequisites, a stated order,
and four new tests asserting the prerequisite graph is acyclic, points only at live
labs, always runs backwards, and chains through every lab exactly once.

**Every lab now ends somewhere** — vocabulary, previous, next, and an invitation to
report confusion, which is the only feedback channel a site with no accounts and no
analytics has. 13 new glossary terms, because textures and compute had none and that
panel would have shipped empty for a third of the labs.

**Every lab shows the code that draws it.** The largest hole on the site, and invisible
to the roadmap until a critic found it: `CodeBlock` existed and was used only on the
technology pages, so a reader could finish a lab having never seen a line of the source
— on a site whose thesis is that the plumbing *is* the subject.

**Presets.** Three or four saved states per lab, each with a sentence on what to look
at. "The normal-matrix bug" squashes the sphere and turns off the inverse-transpose in
one click. Some labs opened with sixteen controls and no indication which to move.

**A usable phone layout.** Canvas, then the controls driving it, then the readout — it
had been canvas, readout, controls, so the slider sat two screens below the render it
changed. And `touch-action: none` everywhere meant a visitor who began a scroll on a
canvas got a page that refused to move.

**A public [roadmap](/roadmap)** — four phases, and five proposals declined in the open
with the real reason, because declining well is most of a roadmap.

## What we fixed

- **A shader test that catches what nothing else does.** Every shader here is a
  template literal, several assembled by concatenation, so a renamed uniform passes
  the type checker, passes both suites, passes the build, and shows the reader an
  error card. Verified by mutation: renaming `uViewProjection` is invisible to `tsc`
  and to both existing suites, and the new one catches it. Seven checks, no browser,
  milliseconds.
- **CI at last.** The tests only ever ran because Vercel executes the build — a branch
  was first verified by deploying it. Now GitHub Actions runs them on push and PR, and
  the link checker weekly, deliberately outside the deploy path.
- **The theme toggle no longer rebuilds the scene.** It threw away a WebGL context and
  recompiled every shader on each toggle, against a browser ceiling of about sixteen
  contexts. The axes are the only thing a palette change invalidates, so they are
  re-uploaded in place.
- **A regression I caused and caught.** Releasing the GL context on unmount looked
  correct and broke every lab: `getContext()` returns the *same* object for a canvas,
  so losing it on cleanup kills any remount that reuses the element — which React's
  StrictMode double-invoke does on every mount. Reverted, with the reasoning recorded
  where the next person will look.

## Key decisions

- **Not duplicating the labs per technology.** Four labs times four APIs is sixteen
  implementations of identical maths. The concepts stay API-neutral; each lab uses the
  API it needs; choosing between them is its own tool.
- **A string-level shader test rather than a Playwright suite.** The proposed
  browser-based smoke test would have been the highest-maintenance item on the list for
  one person working evenings, and a skipped suite is worse than none because the
  README still claims it.
- **Declining the embed route, the tour framework, accounts, and the static export.**
  All on the published roadmap with reasons.
