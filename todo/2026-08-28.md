# 2026-08-28 — Render Quest rebuilt around interactive labs

## What We Built

**A product, instead of a landing page with a tutorial bolted on.** Render Quest is
now a set of interactive graphics labs: you drag the numbers and the matrix, the
geometry and the rendered pixels all change together. Two labs are live.

- **The Model Matrix** (`/labs/transform`) — translate, rotate and scale a cube with
  live sliders, switch the composition between `T·R·S` and `S·R·T`, and watch the
  4×4 fill in beside the render. The object's basis vectors are drawn *through* the
  model matrix, so the three coloured columns in the readout are literally the three
  coloured arms on the canvas. A wireframe ghost marks where the cube started.
- **Projection & the Frustum** (`/labs/projection`) — the camera's frustum rendered
  as an object in the world, above the picture that same camera produces. Boxes the
  camera is about to clip fade out in the god view *before* they vanish from the
  render below, using the same clip test the GPU runs. Perspective/orthographic
  toggle shows the −1 in the bottom row appearing and disappearing.
- Both canvases are drag-to-orbit.

**Live rendering replaces every image on the site.** The home page hero is the
projection lab with its controls removed — real WebGL, running in the visitor's
browser. There is no longer a single raster image anywhere in the product.

**A verified maths core.** `lib/math/mat4.ts` and `lib/gl/frustum.ts` ship with 32
numeric checks (`npm test`) covering composition order, the perspective divide,
near/far mapping to NDC, `lookAt` orthonormality, inverse round-trips, frustum
corner derivation and the clipping test. `npm run build` runs them first, so a
deploy cannot ship broken maths.

## What We Fixed

- **The AI-generated imagery is gone.** The hero was a DALL·E image with garbled
  fake text baked in ("OPENGL" warped, "RENDERING" mangled) and the logo was a
  generic sticker of pencils and a mountain. That was ~3 MB of stock art on a site
  about GPU rendering. Replaced with a live canvas and an SVG mark — an eye, a near
  plane and a far plane, the diagram every graphics course draws in week one.
- **The site stopped advertising things that do not exist.** `/tutorials` listed six
  tutorials and shipped one; five were live 404s, every landing-page card linked to
  `#`, and the header's Login button 404'd. Labs now carry a `status`, and anything
  unbuilt renders as a plainly-marked "Building" card that is not a link.
- **A published privacy page that was unfilled placeholder text** (`[Add details
  about the information you collect]`) has been replaced with an honest one. The
  unused Terms page is gone.
- **The render loop leaked.** The old runner called `new Function(code)(canvas)` and
  the step-4 code started a `requestAnimationFrame` loop nothing ever cancelled, so
  every "Run Code" stacked another loop on the same canvas. The new `GLCanvas` owns
  one loop per mount, cancels on unmount, tracks its container at device-pixel
  resolution, and reads control values through a ref so moving a slider never
  restarts or duplicates the loop.
- **The fonts were never applied.** `layout.tsx` set `--font-sans` / `--font-display`
  while `tailwind.config.ts` referenced `--font-space-default` / `--font-space-display`.
- **The ground plane sliced through the geometry.** Scene objects were centred at
  y = 0, so the y = 0 grid cut every box in half — visible as horizontal lines
  through solid faces, worst in orthographic. Objects now rest on the floor.
- Footer said "© 2024 Human Quest".

## Key Decisions

- **vgpu is not in the critical path, deliberately.** It is real and good (MIT, Node
  22, first-class Next.js loader), but it is WebGPU-only and its purpose is to hide
  exactly the plumbing these labs exist to expose. Matrix and projection explorables
  need the classic pipeline made visible. A clean seam is left for a vgpu-powered
  shader lab, where it would genuinely earn its place.
- **Raw WebGL, no scene graph.** The plumbing a framework hides is the subject.
- **The Shipixen landing template was deleted, not restyled** — testimonials, social
  proof, sale CTAs, marquee, ratings. Nothing is for sale and there were no
  thousands of developers.
- **Column tinting is structural, not decorative.** In a column-major transform the
  first three columns are the transformed basis and the fourth is the translation,
  so the readout tints by column and the canvas uses the same three colours.
- **LSL_GL_Tutorial stays private source material.** The 2005 curriculum informs what
  the labs teach; per the brief there is no visible LSL or heritage branding.

## Breaking Changes

- `/tutorials` and `/tutorials/getting-started-with-webgl` are removed; `/labs` and
  `/labs/<slug>` replace them. Permanent redirects are configured in
  `next.config.mjs`, so the live URLs keep working rather than 404ing.
- `/terms` removed. `/login` was already a 404 and its nav entry is gone.
- Dependencies dropped: Monaco editor, all Radix packages, react-markdown, remark,
  rehype, lucide, cva, clsx, tailwind-merge, tailwindcss-animate, Tailwind forms and
  typography plugins. Runtime deps are now next, react, react-dom.
- Requires Node ≥ 22.6 to build (the test runner uses native TypeScript stripping).

## Not Done Yet

- The two "Building" labs: Coordinate Spaces, Light & Normals.
- An OG image — social cards currently fall back to text metadata.

# 2026-08-28 (part two) — All four labs, light mode, and a reading path

## What We Built

**The two remaining labs, so nothing on the site says "Building" any more.**

- **Coordinate Spaces** (`/labs/pipeline`) — steps one cube corner through Model →
  World → View → Clip → NDC → Screen, morphing the geometry between spaces and
  printing that vertex's coordinates at every stage. The camera frustum drawn in the
  canvas is not separate artwork: it is the same frustum pushed through the same
  function, which is why it lands exactly on the −1…1 cube at the NDC stage. Watching
  `w` pick up the depth at the clip stage, and every later row being that point
  divided by it, is the entire lesson.
- **Light & Normals** (`/labs/shading`) — a lit sphere with flat / Gouraud / Phong,
  live ambient, diffuse, specular and shininess terms, and a movable light. The
  centrepiece is a `stretch y` slider paired with an inverse-transpose toggle: at
  uniform scale both normal matrices agree, and the moment you squash one axis the
  naive one visibly slides the lighting off the surface. That is the bug, made
  reproducible in two clicks.

**Light mode, and a theme system worth the name.** Every colour is now a CSS custom
property with a light and a dark value. That includes the canvases: the WebGL clear
colour, grid tint, axis colours and ambient level all come from the active palette,
so the scenes belong to the page rather than sitting on it as dark rectangles. An
inline head script stamps the theme before first paint, so there is no flash. The
choice follows the OS until you override it with the header toggle.

**A curated reading path** (`/learn`) — 37 resources across two tracks, Graphics and
Games, arranged in nine stages so each one makes the next easier. Every entry says
why it earns your evenings rather than just listing a URL. Filter by kind, search,
show only free resources, and tick items off; progress is kept in your browser with
a per-track progress ring. `npm run check:links` verifies every URL.

**More visual UI.** Each lab card now carries a small hand-drawn SVG diagram of the
thing it teaches — the translation column picked out of a matrix grid, a frustum in
profile, the shape-changing pipeline chain, a lit sphere with its incoming ray. SVG
rather than four more WebGL contexts: crisp, theme-aware, and free.

## What We Fixed

- **The push would have broken the deploy.** The Vercel project is pinned to Node
  20.x, and the test runner used `--experimental-strip-types`, which does not exist
  before Node 22.6. Moved the suite to `tsx`, which runs on Node 18+, so `npm run
  build` — tests included — works on the toolchain that actually deploys.
- **A UV sphere emits degenerate triangles at its poles.** Caught by a test asserting
  flat normals are unit length: the pole quads collapse to a point, giving a
  zero-length cross product and black facets under flat shading. Fixed at the source
  by emitting a triangle rather than a quad at each pole.
- **The reading list contained one link that a real browser refuses.** `ldjam.com` is
  serving an expired TLS certificate, so visitors would meet a security warning.
  Replaced with itch.io's game jams. Two further hosts (Shadertoy,
  realtimerendering.com) return 403 to automated requests but load fine in a browser;
  they are now flagged in the data with the date they were verified by hand, and the
  checker reports them separately instead of crying wolf.
- **The Learn cards' checkboxes were unclickable.** The card-wide link overlay
  (`after:inset-0`) sat above them. Found by trying to click one.
- **The ground plane cut through the sphere** in the shading lab, exactly as it had
  through the boxes in the projection lab. The floor now sits below the geometry.
- **TypeScript was compiling to ES5** — there was no `target` in `tsconfig.json` at
  all, so iterating a `Set` was an error. Set to ES2020, and dropped a `typeRoots`
  entry pointing at a directory that no longer exists.
- The projection lab's stages were framed for one scale; each coordinate space now
  sets its own observer distance, so no stage overflows or vanishes.

## Key Decisions

- **SVG glyphs rather than live canvases on the lab cards.** Four more WebGL contexts
  on the home page to show four thumbnails is a poor trade; a drawn diagram of the
  concept communicates more anyway.
- **Progress is local-only and says so.** No account, no sync, no server. The privacy
  page was updated in the same change to name both things now kept in local storage
  (theme and progress) — a privacy page that goes stale is worse than none.
- **Link checking stays out of `npm run build`.** A deploy should not fail because
  somebody else's server is having a bad afternoon. It is a separate command to run
  when the reading list changes.

## Breaking Changes

- Requires Node ≥ 18.18 (was ≥ 22.6). This is a loosening, not a tightening.
- `tsconfig.json` now sets `target: ES2020` and `allowImportingTsExtensions`.
