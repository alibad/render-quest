# Turning off the Monday pull request

## What we fixed

**Dependabot version updates are off.** Every Monday this repository opened
between one and five pull requests to bump development dependencies and GitHub
Actions. Each one sent mail, each one triggered a Vercel preview and a comment
that sent more mail, and each one then sat there waiting to be read and merged
by the one person who works here.

What it bought: a three-dependency static site stayed a few patch versions
fresher than it otherwise would. There are no accounts on this site, no user
data, no server to attack and no build that breaks from a `@types/node` minor.
The drift that setting protects against is close to free here; the attention it
costs is not.

`open-pull-requests-limit: 0` on both ecosystems. The grouping, the schedule and
the Tailwind 4 note are all kept, so raising the two limits restores the quiet
shape rather than a pull request per package.

**Security updates are untouched and still on.** They are explicitly exempt from
that limit — GitHub opens those from the alert itself, not from
`.github/dependabot.yml` — so an actual advisory still arrives as a pull
request. Today there are zero open alerts on this repository, which is what the
Next 16 upgrade on 2026-09-10 bought.

## Key decisions

- **Turning off the source rather than muting the inbox.** Setting the
  repository to "ignore" in GitHub's notification settings, or unticking
  Dependabot mail account-wide, would also have stopped the noise — and would
  have stopped the first issue a stranger files, which on this repository is the
  only signal there is. The pull requests are what is unwanted, so the pull
  requests are what stopped.
- **Keeping the file rather than deleting it.** A deleted `dependabot.yml` also
  disables version updates, but it takes the reasoning with it, and the next
  person to want them back gets no shape to restore. The limits are the switch;
  the comment above them is the argument.
- **Not silencing the Vercel bot.** `{"github": {"silent": true}}` in a
  `vercel.json` would stop the deployment comments that ride along on these
  threads. It would also stop them on pull requests from people, where the
  preview link is the useful part. Left alone.

## Not done here

The four open Dependabot pull requests (#56, #57, #59, #69) are still open —
closing them was blocked by a permission prompt this session could not clear.
They are the last of the version updates; with the config off, nothing will
replace them once they are closed.
