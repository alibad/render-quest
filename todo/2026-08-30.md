# 2026-08-30 — The rest of the roadmap

Seven items were outstanding: three marked `next`, four marked `later`. All seven
are built. The roadmap page now has nothing left on it that is not shipped.

## What we built

**A link that carries the state.** Every lab's controls serialise into the address
bar and restore from it, with a copy button that appears only once something has
actually been moved. Only values that differ from the defaults are written, so a
link says exactly what was changed and nothing else, and the query is sorted so
the same configuration always produces the same URL.

A shared link is user input that reaches a uniform — and, in the instancing lab,
a draw loop. `?count=1e9&mode=per-object` would have issued a billion draw calls
and hung the tab. Values are coerced against the types their defaults imply,
out-of-range ones are rejected by per-lab guards, unknown keys are ignored.

Twelve tests cover the codec, and writing them found a real bug: `?scale=`
parsed as `Number('')`, which is `0` and finite, so an empty value sailed
through as a real setting and would have collapsed the geometry with no error
anywhere.

**A rendering smoke test — the third attempt at one.** Every lab loaded in a real
browser and checked for console errors, for its own failure card, and for whether
the canvas drew anything at all.

The obvious implementation was wrong twice, and only mutation testing found it.
Screenshotting a canvas does not capture WebGL content in headless Chromium at
all; and because this site's body carries a blueprint grid, that grid showed
through the transparent canvas and measured as detail. **The first version passed
with every single lab blanked.** It reads the canvas in the page now, sampling
across frames because a lab's rAF and the sampler's race for position. WebGL
clears its drawing buffer the moment it is composited, so `GLCanvas` takes
`preserveDrawingBuffer` from a flag the test sets before the app loads — off, and
free, in normal use.

Thresholds were calibrated against measurements, not guessed: the first guess
failed two healthy labs. The pipeline lab is legitimately almost monochrome at 19
colours; a blank canvas measures 1.

**Colour & Gamma (lab 8), and the correction it prompted.** A slider splits one
lit sphere down the middle and lights the two halves in different colour spaces —
same geometry, same light, same Lambert term. Plus a grey test: a one-pixel
black/white dither is physically 50% light, and comparing it against `0.5` and
against the correctly encoded 50% is the shortest proof those are not the same
colour.

The correction is the more important half. **Every shader here multiplied
sRGB-encoded values and wrote them straight to the framebuffer** — the most common
bug in real renderers, precisely because it does not look like one. It darkens
midtones and hardens the terminator, which reads as a lighting choice. Fixed in
the shared lit shader and in both of the shading lab's stages; for Gouraud the
encode has to happen after interpolation, or it is a second bug on top of the
first.

**Depth & Transparency (lab 9).** Z-fighting made reproducible from the frustum,
with the arithmetic printed beside the picture so the failure can be predicted
before it appears — set the separation below the resolvable gap and the panels
must fight. Then a transparency scene where depth writing and sorting can each be
switched off to see what each was for.

**The first build of it never actually fought.** The distance control moved the
camera along with the panels, so the view distance was pinned at 14 units however
far away the slider said they were, and the scene was always well inside
precision. Measuring caught it; looking at it did not.

**Write a Shader (lab 10).** An editable fragment shader that recompiles on every
keystroke, with the driver's own error text and the line it objected to
underneath — renumbered past the preamble so it points where you would actually
look. The canvas keeps the last shader that compiled, so a typo leaves your
picture on screen rather than replacing it with black.

**A second reference scene across all four technologies.** The plasma is a
full-screen effect: no geometry, no camera, no depth buffer, and therefore almost
nothing to compare. A lit, depth-tested, spinning cube needs three vertex
attributes, an index buffer, a matrix chain, a normal transform and depth state —
and that list is exactly where the four stop looking alike. Running in WebGL and
WebGPU; code for all four, with both line counts in the comparison table.

**The chooser has its own address.** `/tech/choose`, with its own title,
description and social card, embedded back into `/tech` rather than the other way
round. "Which should I use" is a question people type into a search box.

## What we fixed

- **The shader suite's precision rule was about to produce a false positive.** The
  shader-writing lab supplies uniforms through a preamble, so the preset bodies
  legitimately declare no precision of their own. Rather than loosen the rule,
  the detection was made precise: a literal is exempt only if it declares nothing
  at all AND its file contains a preamble that does declare one. Verified by
  removing `precision` from a real standalone shader and watching it still fail.

## Key decisions

- **Measuring rather than looking, twice.** Both the depth lab and the smoke test
  looked correct on screen and were wrong. Neither would have been caught by
  reading the code or glancing at the render.
- **The smoke test stays out of `npm run build`.** Vercel runs that, and Vercel
  has no browser. It has its own CI job that installs Chromium.

# 2026-08-30 (later) — Covering it everywhere

Ali had spotted a couple of the gaps himself and asked, reasonably, that the
whole site get swept rather than the one place he happened to look. Two sweeps
ran: a six-lens audit of the repo with every finding adversarially verified
before it was allowed onto the fix list, and a live pass over all 23 production
routes at desktop and phone width.

## The one that mattered most

**Every page on the site was sharing as the home page.** Posting a link to the
shader lab put the home page's title, the home page's description and the home
page's URL into the card, with the lab's own image attached underneath.

Next merges metadata shallowly: a page that sets `title` and `description` but
no `openGraph` inherits the root layout's entire `openGraph` object — and the
root set `title`, `description` AND `url`. Every one of the 23 routes was
affected. Verified against production before touching anything, and again after.

The fix is structural rather than 23 corrections: routes call a
`pageMetadata()` helper, and a test asserts every route uses it. The first
version of that test exempted `[slug]` directories as "generated" — which is
exactly where the last broken route was hiding, so `/tech/webgpu` sailed through
the check written to catch it. Dynamic routes are no longer exempt.

**Related, same page:** `/tech/[slug]/opengraph-image.tsx` had a
`generateImageMetadata` returning one entry per technology. That API is for a
route serving several images, not one image per dynamic segment — so every
technology page emitted all four cards, and the first `og:image` a scraper met
on /tech/webgpu was the one named `webgl`. Deleted; one card per slug now.

## Gaps that were holes

- **/labs/pipeline scrolled sideways on a phone.** A grid item defaults to
  `min-width: auto`, so the readout table's 458px min-content widened the whole
  column inside a 375px viewport and the table's own `overflow-x-auto` was
  powerless. `min-w-0` on the layout's three children. The smoke test missed it
  because it checked four hand-picked routes and this was not one of them — it
  checks every route now, and names the offending element when it fails.
- **The card added to close the lab grid had re-opened it.** Written when there
  were seven labs, where one extra card completed the row; at ten it made
  eleven. It sizes itself against the count now.
- **Three reading-path stages ended on a half-empty row.** The last card widens
  when a stage has an odd number.
- **/privacy was reachable by nothing** — in the sitemap, in no nav, in no
  search index. Footer link and search entry added; a test now fails if anything
  in the sitemap has no inbound link.
- **Four routes had no social card at all**, falling back to the home page's.

## Claims that had gone stale

Four labs and a second reference scene had shipped since some of this prose was
written:

- The search dialog offered "five labs, four technologies, 33 terms" against a
  site with ten and sixty-one. Counted from the registries now, not typed.
- `/tech` said the labs "are all built on it [WebGL]" — two are WebGPU.
- `/labs` promised "drag inside any canvas to orbit the camera"; several labs
  have no camera to orbit.
- The compute lab's fallback still said "the other four labs run on WebGL".
- The roadmap thesis counted six explorables; a declined item did arithmetic on
  "four labs times four APIs".
- Four places still described the technology comparison as one identical scene.
- `/roadmap` is headed "what is being built" and showed 14 shipped, 0 next,
  0 later with no explanation — two bare zeroes under a forward-looking heading.
  It now says plainly that the plan is finished and what would reopen it.
- `/about` ended "They ship when they teach something properly" where "They"
  referred to a list that is now always empty.

## Contradictions the reader would have hit

- **On /tech/webgpu the cube caption said "Live · running on WebGPU right now"
  unconditionally** — printed by the page, which cannot know whether the device
  started, directly beneath a panel saying this browser has no WebGPU. The
  caption lives in the component now and follows its status, as the sibling
  plasma already did.
- The WebGPU plasma's fallback pointed at "the WebGL demo above", which is not
  on that page. It links to /tech/webgl instead.
- The instancing readout showed **0.00 ms in the "good" green and 0 fps** on any
  browser that never ran it — the readout lying about the single number the lab
  exists to show. Unmeasured stats read as em-dashes; draw calls and triangles
  stay, because those are arithmetic on the controls and remain true.
- The colour and depth canvases were the only two with `role="img"` and no
  accessible name.
- `/learn` sends readers outward to other people's material and then stopped
  dead. It ends by pointing back at the labs and the glossary.

## Key decisions

- **Structural over corrective, wherever it was available.** Counts derived from
  registries cannot go stale; a metadata helper plus a test cannot be forgotten
  one page at a time. Three of the bugs above were second occurrences of a bug
  already fixed once by hand.
- **Verifying the verifier.** 36 audit findings, each attacked by a second agent
  told to refute it. Several were duplicates across lenses and one was refuted
  outright; the survivors were then re-checked by hand against production before
  any of them were treated as real.

# 2026-08-30 (last) — Closing the parity gaps

The sweep had found the holes; this pass fills the ones that were left, all of
them the same shape: an affordance a reader learns on one lab and does not find
on the next, arriving quietly with each new lab rather than as a decision.

## What we filled

**Three labs had no presets.** Projection, Pipeline and Compute opened with a
column of sliders and nothing to suggest which one was worth moving, while the
other seven opened with somewhere to start. Four each now, written against what
each lab actually teaches — exaggerating the perspective divide, turning the
compute lab's swirl off so the field collapses into a single dot, jumping the
pipeline straight to the moment w stops being 1.

**Three labs built a camera and gave no way to move it.** Colour, Depth and
Textures. Orbit added to all three, in the controls rather than a ref, so a
shared link carries the angle the reader judged it from — verified by dragging
each canvas and confirming both that the image changes and that the URL picks
the angle up.

Textures is the interesting one: it had a fixed viewpoint down a receding plane,
and the viewing angle is not decoration there. Flattening it lengthens the
texture footprint of every pixel, which is exactly what minification has to
cope with, so being able to look along the plane is part of the lesson. The
elevation is clamped above the ground, because below it there is nothing to see.

The two labs that still do not orbit — the particle field, drawn straight in
clip space, and the full-screen shader — have no camera to move, and the test
now asserts they contain no `lookAt` so that stays true rather than being
assumed.

**The shader lab showed none of its own source**, on the one page where the
hidden code matters most: it silently prepends a preamble declaring the four
uniforms, which is why `vUv` exists without being declared and why the driver's
line numbers sit a few higher than the editor's. Both the preamble and the
vertex shader are on the page now. Its canvas also gained the failure overlay
every other lab has — a browser with no WebGL context used to get a blank
rectangle and the explanation in a panel headed "what the compiler said".

**27 of 37 reading-path resources carried a grading nobody was shown.** `level`
was set on every resource and rendered only on the ten marked "start here", so
core and go-deep looked identical, and "The hard systems" was the one stage with
no way in at all. All three levels render now, and a test fails if any stage
loses its starting point.

**Three.js had two code samples where niche vgpu had four** — on the technology
the site calls the default answer for most 3D on the web. Added the two things
every real Three.js scene needs and nobody enjoys writing: loading a glTF model,
and orbit controls with a correct resize.

## What we corrected

The home page's own statement of principle said **"Every lab shows the live
matrix next to the render"** — true of three labs out of ten. It now claims what
is actually shared: the numbers driving the render are on screen beside it,
whichever numbers those are.

And `/labs` can promise the orbit again. It was softened last pass to "where a
lab has a camera to move" because five labs had none; with eight of ten orbiting
and the other two saying plainly why they cannot, the strong version is true.

## Key decisions

- **Three new tests, not three fixes.** Presets, source panels and camera
  controls are each asserted across all ten labs. Every one of these gaps
  arrived by a new lab simply not having something, which is exactly the failure
  a per-lab check catches and a code review does not.
- **Declaring the exceptions rather than exempting them.** The parity check
  names the two cameraless labs and then verifies the claim, failing if either
  ever calls `lookAt`. An exemption nobody re-checks is how /tech/webgpu hid
  from the metadata test earlier today.
