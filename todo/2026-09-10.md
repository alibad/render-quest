# The repo went public with no terms, and the README asked you to imagine WebGL

Twelve issues from the backlog, all of them things a stranger hits before they
reach anything the site is actually good at.

## What we fixed

**There was no licence.** The repo went public and `licenseInfo` came back
`null`, which means a lecturer could not legally assign a paragraph — the exact
use the 20,000 words were written for. Now dual-licensed the way the sibling
repo does it: `LICENSE` is MIT for the code, `LICENSE-CONTENT` is CC BY 4.0 for
the prose, figures and curated lists, and it opens by saying plainly which files
fall under which.

`LICENSE` is the plain MIT text and nothing else, deliberately. The first draft
carried a two-line scope note above the body; modelling GitHub's detector
against it scored **92.46% where the threshold is 98%** — the note is a full
sentence, so nothing strips it, and it injects fifteen words MIT does not
contain. The sidebar would have stayed empty. The note now lives in
`LICENSE-CONTENT` and the README, along with the reason it is not in `LICENSE`,
so the next person to notice the gap does not put it back.

**The README had no pictures.** A repo whose thesis is that you cannot see a
motion on a static page was asking a stranger to imagine the one thing it exists
to show. It now opens with three first-party captures, produced by
`scripts/capture-readme-media.ts` from the real site in headless Chromium — the
translate slider dragged out to 1.50 and back with one number in the matrix
moving; the frustum above and the picture it produces below; a shader that will
not compile with the driver's own error reprinted.

The GIF encoder is hand-rolled in the script. Nothing in `devDependencies` can
write a GIF, and GitHub does not autoplay `.webm` in a README — which is the
whole point of the file.

**Three claims in the README were false, and the counts are now tested.** It
said `npm test` runs 69 checks (it runs 89, across seven suites), and that four
technology guides render two identical scenes (two of the four are
`demo: 'code-only'` and the site's own About page already said so).
`test/readme.test.ts` now fails if the lab table, the glossary count, the live-lab
count, the tagline, the site URL or the stated suite count drift from the source.

**Four more pages were making the same wrong claim**, and the new
`test/technologies.test.ts` found them: the home page, the /tech social card,
/about and /tech/choose all told the reader that Three.js and vgpu render. They
now derive the sentence from the registry — `RUNS_HERE` and `CODE_ONLY` — so it
cannot be wrong again without the suite going red.

**The line counts contradicted each other one page down.** /tech printed "24
lines" from a counted figure while /tech/three printed "~24 lines" from a
hard-coded tilde directly above it, and every tilde on the home page was false —
all four plasma figures are counted. There is now one `lineFigure()` helper in
the registry, and a check that no page hand-types a tilde in front of a count.

**The link checker cried wolf and then told nobody.** A single connection failure
marked a link dead; now it retries three times, but only for outcomes that could
change — a 404 is a 404 on the third try too. It distinguishes DNS failure, TCP
timeout, TLS error, 4xx and 5xx, because those mean completely different things.
When the weekly run fails it opens a GitHub issue and updates that same issue
rather than duplicating, and closes it when a run comes back clean.

That machinery immediately earned itself: 3Blue1Brown's host times out at the TCP
level after 25 seconds. It is not a moved URL and swapping it would have been the
wrong fix. The card now says so, and /learn no longer promises "every link is
checked" above its own counter-example.

**A stranger arriving had nowhere to go.** `CONTRIBUTING.md` now says what this
project will and will not accept — raw WebGL and WebGPU, no scene-graph
dependency, no analytics, no cookies, no third-party requests — so nobody spends
an evening on a Three.js pull request. Three issue forms, including one for "this
sentence is wrong", which is this site's most likely inbound report and the one a
generic bug form handles worst. Plus a PR template, a code of conduct, and
Dependabot.

**Also**: a favicon and apple-touch icon that survive 16px, a web manifest,
`npm run lint` in CI, a licence line in the footer, and `"license": "MIT"` in
`package.json`.

## Settings changed outside the repo

Branch protection on `main` (CI must pass, no force pushes, no deletion, admins
exempt so deploy-on-push still works), Dependabot alerts and security updates,
and GitHub Discussions — the issue templates link to it.

## Key decisions

**CC BY 4.0 for the prose, not BY-SA.** The sibling repo uses ShareAlike. The
point here is a lecturer lifting a paragraph into their own slides without
inheriting a share-alike obligation, so the stronger copyleft would defeat the
reason for licensing the prose at all.

**The cube line counts stay estimates.** Deriving them would have printed 21 for
WebGL's cube against Three.js's 24 — the table would have claimed hand-written
WebGL is shorter than Three.js, which is false. The listings are excerpts, so the
estimate says what it excludes instead.

Closes #1, #8, #9, #10, #11, #12, #13, #14, #18, #34, #37, #38, and #4 in
settings.
