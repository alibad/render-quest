## Setting up the WebGL Context

In this step, we'll initialize the WebGL context and set a random background color. This is the crucial first step in any WebGL application.

1. First, we get the canvas element from the DOM.
2. Then, we try to get the WebGL context from the canvas.
3. If successful, we set a random clear color and clear the buffer.

Try running the code and see the canvas change to a random color!
